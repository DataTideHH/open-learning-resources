## Why this resource is useful

Spring Data JPA is useful for learning and reviewing:

- repository abstractions
- CRUD-oriented data access
- entity persistence
- derived query methods
- transaction boundaries
- pagination and sorting
- projections and specifications
- the relationship between JPA and Spring repositories

This resource directly supports the persistence layer used in the [`spring-boot-process-api-basics`](https://github.com/DataTideHH/spring-boot-process-api-basics) project.
