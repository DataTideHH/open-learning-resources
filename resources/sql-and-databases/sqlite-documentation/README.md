## Why this resource is useful

SQLite is relevant for compact, reproducible data and API projects that need:

- a file-based relational database
- SQL constraints, views and indexes
- portable local persistence without a database server
- testable data-quality and reporting workflows
- integration with Python and Flask

This reference supports `flask-country-data-api`, `music-production-data-lab` and `network-operations-data-lab`.

## Important note

SQLite has deliberate differences from client/server database systems, including flexible typing. The official documentation should be used to understand SQLite-specific SQL behavior and constraints.
