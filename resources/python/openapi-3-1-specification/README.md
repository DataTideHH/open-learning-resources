## Why this resource is useful

OpenAPI provides a language-agnostic contract for HTTP APIs. It is useful for documenting and reviewing:

- paths and operations
- request parameters and bodies
- response schemas and status codes
- reusable components
- authentication and security schemes
- machine-readable API validation and documentation

This reference directly supports the versioned API contract in `flask-country-data-api`.

## Version note

The catalog tracks the OpenAPI 3.1 feature family through patch version 3.1.2. Patch releases clarify or correct the 3.1 specification without defining a new minor feature set.
