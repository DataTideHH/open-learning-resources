## Why this resource is useful

pytest is relevant for small, auditable Python projects that need:

- automatic test discovery
- readable assertions and failure output
- fixtures for controlled test data and resources
- parameterized contract and edge-case tests
- repeatable local and CI validation

This reference supports the automated tests used across current Python DataTideHH repositories.

## Important note

Tests should verify business rules, data contracts, reconciliation controls and failure behavior rather than merely execute code paths.
