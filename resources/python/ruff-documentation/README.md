## Why this resource is useful

Ruff provides a fast, unified Python linting and formatting workflow. It is useful for:

- deterministic code-style checks
- static detection of common Python issues
- import ordering and modernization rules
- formatter checks in CI
- centralized configuration through `pyproject.toml`

This reference supports the `ruff check` and `ruff format --check` controls used across current Python DataTideHH repositories.

## Important note

Linting and formatting improve consistency and catch selected defect classes, but they do not replace tests, type checks or domain validation.
