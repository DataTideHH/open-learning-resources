## Important note

This is a link-only reference entry.

DAX is used across Power BI, Analysis Services and Power Pivot. Product support for newer functions can vary, so the current documentation and the target product version should be checked together.

## Why this resource is useful

DAX is useful for learning and reviewing:

- measures
- calculated columns and tables
- filter and row context
- aggregation and iterator functions
- time-intelligence calculations
- relationships and semantic-model calculations
- DAX queries
- row-level security expressions

This reference complements the Power BI, Power Query and star-schema resources already included in this repository.
